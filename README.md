# Квест «Петрозаводск за один день»

Телеграм-бот для пешего маршрута. Человек открывает бота по ссылке, слушает аудио, смотрит фото и отвечает на задания. За верный ответ приходит штамп в паспорт путешественника. В финале бот присылает общий разворот со всеми штампами.

## Как проходит квест

На `/start` бот показывает приветствие и две кнопки: «Начать квест» и «Хочу посмотреть маршрут». Маршрут открывает [закладки на Яндекс Картах](https://yandex.ru/maps/?bookmarks%5BpublicId%5D=vLHBIAZT) и возвращает в меню.

Дальше девять точек. На каждой — аудио, фото и текст, затем кнопки с вариантами. Неверный ответ объясняет, почему мимо, и кнопка «Попробовать ещё раз» возвращает к заданию. Верный ответ присылает пояснение и штамп, затем открывает следующую точку.

Точка 3 — проспект Карла Маркса — устроена иначе: четыре аудио (проспект, Главпочтамт, МВД, универмаг «Карелия»). Между ними кнопка «Дальше». Задание про фасад «Кареллеспрома» стоит в конце, у универмага, и за него приходят сразу два штампа.

После библиотеки вместе со штампом уходит переход: Дом физкультуры, смотровая площадка и лестница к озеру, и только потом ЗАГС.

Прогресс хранится на сервере. Если человек закроет чат, «Начать квест» продолжит с текущего места. Команда `/reset` стирает прогресс.

В исходном тексте точки 1 пояснение верного ответа подписано «ответ В», но сама фраза про крыло вдоль проспекта Ленина. В боте верный вариант — «Крыло вдоль проспекта Ленина».

## Штампы

В папке на Диске были тексты, фото и аудио. Отдельных картинок штампов не было, поэтому бот рисует паспортные штампы сам и в финале собирает их на один разворот. Файлы лежат в `media/stamps/`: `01.png` … `10.png` и `spread.png`.

Чтобы подставить рисунки Ксении, замените эти png и заново соберите разворот:

```bash
python3 scripts/make_stamps.py
```

Скрипт не трогает уже лежащие штампы, только переклеивает разворот. Полностью перерисовать штампы: `python3 scripts/make_stamps.py --force`. Нужен шрифт DejaVu (`fonts-dejavu-core`).

## Что нужно, чтобы бот ожил

Токена пока нет. Его создают в [@BotFather](https://t.me/BotFather): `/newbot`, имя и юзернейм. BotFather отдаёт токен вида `123456:ABC...`. Ссылку на бота (`https://t.me/юзернейм`) можно отправлять туристам: в поиске бот не обязателен, квест идёт в личном чате.

На сервере (Ubuntu, локация не Россия) токен кладётся в файл `.env` в корне проекта:

```
BOT_TOKEN=123456:ABC...
```

## Запуск на сервере

Код кладётся в `/opt/kvest-bot`. На тарифе без Docker достаточно Python:

```bash
sudo apt update
sudo apt install -y python3-venv python3-pip fonts-dejavu-core
cd /opt/kvest-bot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
nano .env
.venv/bin/python -m bot --check
sudo cp deploy/kvest-bot.service /etc/systemd/system/kvest-bot.service
sudo systemctl daemon-reload
sudo systemctl enable --now kvest-bot
sudo systemctl status kvest-bot
```

Логи: `journalctl -u kvest-bot -f`.

Если Docker уже стоит:

```bash
cp .env.example .env
nano .env
docker compose up -d --build
docker compose logs -f
```

Первый турист загружает фото и аудио в Telegram, дальше бот шлёт их по сохранённому `file_id`. База прогресса — `data/bot.sqlite`. Её не нужно коммитить.

Проверка сценария без токена: `python3 -m bot --check`. Тесты: `python3 -m pytest`.
